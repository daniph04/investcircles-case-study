# Media provenance

## Capture method

The screenshots and video in `assets/` were captured from the InvestCircles iOS application running on an iPhone 17 Pro simulator with iOS 26.5.

## Data policy

The media uses a dedicated portfolio-demo account. Every displayed name, balance, holding, trade, circle, message, and relationship was created specifically for this demonstration.

The capture process does not use Daniel's personal account or any production customer's data. Credentials, internal project identifiers, database keys, and admin interfaces are excluded from the media.

## Files

| Asset | Purpose |

| `simulator-home.png` | Portfolio overview and primary product entry point |
| `simulator-portfolio.png` | Holdings, performance, and transaction context |
